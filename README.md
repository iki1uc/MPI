# MPI – Mehrphasen‑Interaktionsraum (iki1uc)

MPI ist die physikalisch‑systemische Grundlage für die 4u‑Response‑Ebene.
Es beschreibt ein Element mit 6 Interaktionszuständen, die vollständig
durch Umgebung (Temperatur, Druck, Soll‑Ist‑Stellung) reproduzierbar sind.

## Interaktionszustände (MPI‑6)
- FIX‑I   → Struktur / Unter‑Soll
- FLOW‑I  → Fluss / Soll
- EXPAND‑I → Expansion / Über‑Soll
- CHARGE‑I → Energieaufnahme
- SHIELD‑I → Energieblock
- RELEASE‑I → Energieabgabe

## Verbindung zu 4u – Response Layer 7
4u bildet die Antwortmatrix:
OK / NOK / FLOW / BREAK / ECHO / VOID / ROOT

MPI liefert die physikalische Grundlage,
4u liefert die systemische Antwort.
